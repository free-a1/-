## 三、运行环境

| 项目 | 说明 |

## 四、重点成果

1. **Linux 基础链路打通**：目录规划 → 用户权限 → 免密 SSH → 后台守护任务，产出 `init_env.sh` 一键初始化脚本。
2. **日志分析能力**：用 grep/sed/awk 三剑客解析推理日志，统计出平均延迟 128.75 ms（4 条样本）。
3. **Python 数据处理闭环**：数据集自动分类（cat/dog）→ 生成 labels.csv → 推理结果 JSON → 格式化报表。
4. **容器化原理实践**：用 unshare+chroot 动手实现容器根文件系统、进程隔离、镜像打包（tar）、数据卷持久化、多容器协作。
5. **推理服务交付**：HTTP 接口（正常 200 / 字段错 400）+ curl 测试 + README 部署文档 + 从零验收，返回 `{"label": "cat", "score": 0.92}`。
6. **迷你 CV 推理**：自建 PPM 图像数据集 → 训练颜色质心模型 → 分类推理并记录置信度与耗时。
7. **性能监控**：编写 monitor.sh 每 2 秒采样 CPU/内存，对比负载前后数据。

## 五、收获与踩过的坑

**最大的收获**：理解了容器隔离的本质——不是"小虚拟机"，而是通过 namespace（进程/网络/挂载）+ chroot 实现的文件系统隔离；也理解了"数据卷"为什么必须外置（容器可写层随容器生灭）。

**踩过最大的坑**：离线 CentOS 环境缺少 Docker / python3 / pip，最初按 Ubuntu 的思路执行 `apt` 全部失败。解决路径：挂载本地 ISO 做 yum 源 → 离线安装 python3/git/tree → 用 unshare+chroot 替代 Docker 完成容器章节，反而更深入地理解了底层原理。

其他记录在案的问题：
- `git -C` 在 git 1.8.3 不支持，需先 `cd` 进仓库再执行 bundle；
- 容器内 `ps` 需要先挂载 `/proc` 才能正常显示进程列表；
- 后台任务用 `kill $PID` 常杀不掉子进程，改用 `pkill -f` 更可靠；
- pip 的 `pip.conf` 与 apt 的 `sources.list` 是两套换源机制，不可混用。
